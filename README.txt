COMO PUBLICAR NO VERCEL
1. Suba esta pasta num repositório do GitHub e importe no Vercel (ou use "vercel" na pasta).
2. Em Settings > Environment Variables, crie:
   FISH_API_KEY      = sua chave da Fish Audio
   ANTHROPIC_API_KEY = sua chave da API da Anthropic (console.anthropic.com)
   APP_SENHA         = uma senha sua (protege seus créditos)
3. Faça o deploy e abra o site. Digite a senha no campo "Acesso".
